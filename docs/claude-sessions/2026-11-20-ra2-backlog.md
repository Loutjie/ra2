# 2026-11-18 to 2026-11-20: Prism, shadows and the RA2 ability backlog

## Goal

Close the gaps between the mod and original Red Alert 2 found in the ability audit and `GAP_ANALYSIS.md`: Prism support and fragments, voxel shadows, then the backlog issues, each on its own branch, all merged into one test branch with a scripted testbed map for play-testing.

## Key decisions

- **One issue per branch, merged only into test branches.** Each feature is `feature/<name>` cut from `main`, pushed to the fork, and combined in `test/backlog-20261120`. Rejected: one big branch, which would make review and selective merging impossible.
- **RA2 behaviour in both balance modes, RA2 numbers only in Exact.** Abilities (self-heal, Iron Curtain on infantry, erasure, bombs) go into the base rules; numbers that are balance (power, ranges, timers) stay as the mod has them, and Exact takes RA2's values through `tools/exact` rules. Rejected: changing default-mode balance numbers to RA2's, which would erase the Reimagined mode's tuning.
- **Prism beams: `GlowLaserZap` (mod copy of `LaserZap`)** draws the glow first and moves the core towards the camera through the depth buffer (`WVec(0,d,d)` keeps the screen position). Rejected: ZOffset tweaks, which z-fought. Upstreaming to the engine is #26.
- **Prism support chains stay on** (`Chain = true`). The user rejected turning them off after an Ares note was misread as "not in RA2".
- **Voxel shadows: ray-traced to the ground along the light direction** with a 2048 lattice and bilinear smoothing, on the fork engine (`Loutjie/OpenRA`, tag `playtest-20261011-ra2.5`, `mod.config` on `feature/fork-engine`). Rejected: the tile under the craft (the shadow jumped backwards at cliffs) and a 1024 lattice (still jumped). Missiles use `ModelRenderable.WithDepthOffset` so their shadows stay put.
- **Self-heal (#10):** `ChangesHealth@SELFHEAL` replaces the elite self-heal on RA2 `SelfHealing=yes` units, because RA2 treats self-heal as a flag (no stacking). The Kirov is left out: it self-heals only in Yuri's Revenge.
- **Iron Curtain kills infantry (#6) in `^Infantry`,** so both modes match RA2; the Exact generator skips infantry that already die.
- **Psychic Sensor (#9):** attack lines of enemy units within 15 cells, drawn over fog for the owner and allies; only orders against enemy actors count. Disguise reveal was split off (#27) and done separately with mod-side render/tooltip traits.
- **Tesla bounce (#11)** reuses the `FireFragments` warhead from the Prism Tank, so it depends on `feature/prism-fragments`.
- **Aegis spread fire (#12):** `DistributedArmament`, an `Armament` subclass that re-aims each missile at the next enemy by actor ID (deterministic). Rejected: retargeting the attack activity, which the engine does not expose. The Exact generator learned `ARMAMENT_TRAITS`.
- **Crazy Ivan (#7):** `AttachIvanBomb` warhead plus `IvanBombCarrier` trait; the bomb rides on its carrier and goes off at once if the carrier dies (my call, believed RA2). The user chose to follow RA2's `Bombable` list, so Conscripts, Engineers and Tesla Troopers can no longer be bombed.
- **Chrono erasure (#5):** warp accumulates at RA2's `Damage` per frame against `Strength x 10`; each hit holds the target for 25 ticks and the beam refires every 20, because the engine hides an attacker's current target (`ChildActivity` is protected). Erased actors are disposed after crediting experience and kill statistics only, so no wreck, explosion or survivors. Not done: RA2 makes the target untargetable by others.
- **Parallel sessions with worktrees made here.** The project folder is not a git repo, so worktrees were created first and sessions started with `cwd` and `use_worktree: false`.
- **Backlog Testbed map:** one Lua-scripted map (copy of `missile-testbed`) with a station per feature and AI-less Creeps targets that hold fire. Rejected for now: the automated pass/fail test maps (#25, parked), which need C# hooks.

## Lessons

- Run the full Python suite from the repo root (`pytest tools`); `pytest` inside `tools/` skips the Exact snapshot guards, and a pushed branch broke them once.
- `make` can exit 0 on a failed build: grep the log for `error`.
